# 宣传资料目录 / Promotional materials

本目录包含所有需要在外部渠道发布的草稿。你只需要复制对应文件的内容、贴到目标平台即可。

## 文件清单

| 文件 | 平台 | 字数 | 预计效果 |
|---|---|---|---|
| `v2ex-post.md` | V2EX（创意/分享创造 节点） | ~200 字 | 中文圈核心地，200-2000 浏览 |
| `show-hn.md` | Hacker News（Show HN） | ~150 字 | 英文圈核心地，1k-10k 浏览 |
| `juejin-article.md` | 掘金 / 少数派 | 2500-3500 字 | 长文，SEO 价值高 |
| `devto-article.md` | dev.to / Hashnode / Medium | ~1800 字 | 英文长文，跨平台发布 |
| `awesome-pr-texts.md` | 各种 awesome-* 列表 | PR 模板 | 4 个 PR，每个 5-30 star |
| `pypi-checklist.md` | PyPI 发布步骤 | 检查清单 | 暂不建议立即发布 |

## 推荐执行顺序（按 ROI）

1. **今天**: V2EX + Show HN（双发，最大曝光窗口）
2. **本周**: dev.to 英文长文（发后会被 Hacker News newsletter / Python Weekly 收录）
3. **下周**: 4 个 awesome-* PR（低投入长期引流）
4. **本月**: 掘金中文长文（中文圈 SEO）
5. **2 周后**: 视 star 数决定是否发 PyPI

## 注意事项

- **不要刷 star**——GitHub 会检测并清零
- **不要批量注册小号**——会触发风控
- **每个渠道的标题都要本地化**，不要直接翻译 V2EX / HN 的标题
- **回复评论**——HN / V2EX 早期回复率决定流量上限
- **不要 spam**——每个渠道只发一次

## 预期累计效果（保守）

| 时长 | stars | 来源 |
|---|---|---|
| 第 1 周 | 30-80 | V2EX + HN |
| 第 1 月 | 100-300 | + dev.to + awesome-* |
| 第 3 月 | 300-1000 | + 长文 SEO + 口碑 |
